# 상태창!! 아트 제작 브리프

## 시각 방향

- 장르: 현대 판타지 / 균열 / 상태창
- 톤: 네이비·검정 기반, 청록과 보라 네온을 강조색으로 사용
- 금지: 서양 카드게임풍, 과도한 SD, 화면 전체를 덮는 번쩍임, 이미지 안의 글자
- 원칙: 배경·캐릭터·이펙트를 분리해 Unity에서 독립 레이어로 조합한다.

## 캐릭터 납품 규칙

- 배경을 절대 포함하지 않는다.
- 발바닥 기준선과 전체 캔버스 비율을 통일한다.
- 한 캐릭터는 `Idle / Attack / Hit / Defeat` 4포즈를 우선 납품한다.
- 광원은 왼쪽 위, 외곽선은 청록 또는 보라 중 하나만 사용한다.
- 원본 PSD/Clip Studio 파일과 레이어 분리 PNG를 함께 받는다.

## 추천 제작 순서

1. 앱 아이콘, 헌터, 훈련 균열 배경, 균열 수호자
2. 훈련 균열의 공격/피격 VFX
3. 나머지 3개 균열 배경과 보스
4. 장비 아이콘·UI 프레임
5. 스킨과 이벤트 전용 아트
