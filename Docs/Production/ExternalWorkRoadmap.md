# Unity 외 작업 순서

1. **P0 아트 의뢰/구매**: 앱 아이콘, 투명 헌터·보스, 훈련 균열 배경
2. **P0 출시 계정**: Google Play Console, 앱 서명 키, 지원 이메일
3. **P0 법무**: 개인정보처리방침과 이용약관 초안 검토
4. **P1 사운드**: 전투 효과음 8개, 루프 BGM 2개, UI 효과음 6개
5. **P1 스토어 자산**: 스크린샷 6장, 피처 그래픽, 앱 설명
6. **P1 수익화**: 보상형 광고 SDK 계정과 테스트 광고 단위
7. **P2 운영**: PlayFab 프로젝트, 시즌 정책, 고객지원/버그 제보 채널

현재 바로 발주할 수 있는 문서는 `ArtProductionBrief.md`와 `GooglePlayListingDraft.md`다.
