## 제작 방식

| 항목 | 권장 방식 | 이유 |
| --- | --- | --- |
| 아이콘·키 아트 | 직접 생성 후 디자이너 보정 또는 의뢰 | 게임의 첫인상이라 품질 기준을 빠르게 정할 수 있다. |
| 캐릭터·몬스터 전투 모션 | 스프라이트 작가 의뢰 또는 검증된 패키지 구매 | 자동전투의 재미는 반복해서 보는 움직임에서 나온다. |
| 전투 VFX | 패키지 구매 후 색·크기 조정 | 초기에 가장 빠르게 타격감을 끌어올린다. |
| UI 프레임·아이콘 | 직접 제작/구매 후 한 팔레트로 통일 | 기능 변경이 잦아 수정 비용을 낮춘다. |
| 사운드 | 상업 이용 가능한 라이브러리 또는 의뢰 | 권리 증빙을 남기고 빠르게 조합할 수 있다. |

## 납품/구매 검수 기준

1. 상업 이용 범위와 출처를 파일별로 기록한다.
2. 캐릭터와 몬스터의 배경은 반드시 투명이어야 한다.
3. 스프라이트는 프레임 크기·피벗·애니메이션 이름을 함께 받는다.
4. 밝은 배경과 어두운 배경 양쪽에서 실루엣을 확인한다.
5. 작은 모바일 화면에서 역할이 즉시 구분되는지 확인한다.
