# 상태창!! 앱 아이콘 v1

## 용도

- Google Play 내부 테스트 및 스토어 등록용 기준 아이콘
- 향후 Unity 런처 아이콘과 소셜 프로필의 시각 기준점

## 원본

- 파일: `StatusWindow_AppIcon_v1.png`
- 콘셉트: **상태창 프레임 속 균열 결정**
- 핵심 색: 딥 네이비 / 시안 / 바이올렛
- 의도: 캐릭터를 쓰지 않아도 작은 크기에서 `상태창!!`의 시스템·균열·성장 이미지를 식별하게 한다.

## 등록 전 처리

1. 원본은 보관하고, Play Console용으로 512×512 PNG를 별도 내보낸다.
2. Android 적응형 아이콘은 중앙 결정과 프레임이 안전 영역 안에 들어오도록 전경/배경을 분리해 제작한다.
3. 작은 크기(48×48)에서 가장자리 장식이 뭉개지면, 같은 콘셉트의 단순화 버전을 v2로 만든다.
4. 실제 등록 전에는 타이틀·스토어 스크린샷과 함께 유사 상표 및 권리 검토를 한다.

## 사용 금지

- 화면 안에 제목, 레벨, 버튼 문구를 덧씌운 버전
- 캐릭터 또는 웹툰 작품을 연상시키는 고유 의상·무기 중심 버전
- 이 원본을 그대로 게임 내 스프라이트 시트로 사용하는 것
