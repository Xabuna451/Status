# Google Play 스크린샷 구성안

목표는 전투 화면만 예쁘게 보이는 것이 아니라, 사용자가 **자동전투 → 빌드 선택 → 보상 → 더 강한 던전**의 흐름을 5장 안에 이해하게 하는 것이다.

| 순서 | 실제 화면 | 상단 카피 | 전달할 약속 |
| --- | --- | --- | --- |
| 1 | 보스 자동전투 | `손대지 않아도, 빌드는 네가 만든다` | 조작 없는 전투와 빌드 중심 게임임을 즉시 보여 준다. |
| 2 | 상태창 / 스탯 분배 | `한 포인트가 전투 방식을 바꾼다` | 성장 선택이 존재한다. |
| 3 | 스킬 노드 | `스킬을 연결해 나만의 전투식을 완성하라` | 액티브·패시브 조합의 깊이를 보여 준다. |
| 4 | 장비 / 세트 효과 | `장비를 바꿔 한계를 돌파하라` | 수집과 빌드 변경의 보상을 보여 준다. |
| 5 | 오프라인 보상 / 다음 균열 | `접속하지 않은 시간도 성장으로 이어진다` | 모바일 방치 성장의 핵심 가치를 설명한다. |

## 제작 규칙

1. 모든 캡처는 세로 9:16, 동일한 폰 비율과 색감으로 통일한다.
2. 각 장은 한 가지 기능만 보여 준다. 작은 설명문을 여러 줄 넣지 않는다.
3. 카피는 이미지 편집 단계에서 올리고, 실제 게임 UI 위에 억지로 넣지 않는다.
4. 숫자는 플레이 가능한 현실적인 값만 쓴다. 과장된 전투력·보상 수치를 쓰지 않는다.
5. 첫 장의 보스·헌터 실루엣이 가장 크게 보여야 한다.

## 현재 확보한 아트

- 앱 아이콘: `Art/StatusWindow_AppIcon_v1.png`
- 세로 키 아트: `Art/StatusWindow_KeyArt_Portrait_v1.png`

키 아트는 실제 플레이 스크린샷을 대체하지 않는다. 1번 스크린샷의 배경·색감 기준으로만 사용한다.
