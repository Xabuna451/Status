# 상태창!! 상품 전략 v1

## 한 줄 정의

**상태창을 열어 빌드를 완성하고, 조작 없이 균열을 돌파하는 세로형 자동전투 성장 RPG.**

## 출시 목표

- 첫 출시: Android 한국어 비공개 테스트
- 플레이어가 첫 10분 안에 `빌드 변경 → 자동전투 → 보상 → 더 강한 빌드`를 이해한다.
- 광고를 강요하지 않고도 기본 진행이 가능한 무료 게임으로 시작한다.
- 온라인 랭킹은 밸런스와 부정행위 검증이 갖춰진 뒤 시즌 기능으로 추가한다.

## 핵심 재미

1. 숫자가 아니라 **빌드 선택**으로 전투 결과가 바뀐다.
2. 직접 조작은 없지만, 전투를 관전하며 다음 투자 방향을 판단한다.
3. 같은 던전도 장비·스킬·전술 지침으로 다른 해법이 생긴다.
4. 더 어려운 균열일수록 새로운 장비와 기록 단축의 목표가 생긴다.

## 플레이어 약속

- 전투 조작을 요구하지 않는다.
- 강제 전면 광고를 넣지 않는다.
- 오프라인 보상은 제공하되, 광고 시청을 강요하지 않는다.
- 과금으로 랭킹 전투력을 직접 구매하게 하지 않는다.

## 초기 수익화 설계

### 1. 보상형 광고만 출시 1차에 적용

- 오프라인 보상 수령 후 선택적으로 `보상 2배`
- 던전 공략 성공 후 선택적으로 `골드 보상 2배`
- 하루 3회 제한, 연속 시청 쿨다운 3분
- 광고 미시청 시에도 핵심 성장·장비 획득은 그대로 진행

### 2. 인터스티셜/배너 광고는 초기 출시에서 제외

자동전투의 흐름을 끊고 리텐션을 해칠 위험이 커서, 지표가 쌓이기 전에는 넣지 않는다.

### 3. 인앱 결제는 2차 출시 후보

- 광고 제거
- 외형 전용 헌터 스킨
- 전투력에 영향을 주지 않는 UI 테마

랭킹 도입 전에는 스탯·장비·던전 보상을 직접 판매하지 않는다.

## 초기 지표

- 첫 던전 입장률
- 첫 던전 클리어율
- 10분 내 빌드 변경 횟수
- D1 / D7 유지율
- 보상형 광고 제안 대비 시청률
- 던전 중단·시간 초과·패배 비율

## 출시 후 우선순위

1. 첫 10분 이탈 원인 수정
2. 던전별 빌드 목적 강화
3. 보상형 광고 A/B 테스트
4. 계정·랭킹·시즌 기능
