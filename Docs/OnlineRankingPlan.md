# 온라인 랭킹 연결 계획

## 채택 구조

초기 출시에는 **PlayFab Leaderboards**를 사용한다. 게임 클라이언트는 점수 제출과 조회만 담당하고, 점수 검증·시즌 초기화·부정행위 대응은 PlayFab CloudScript 또는 서버 API에서 수행한다.

## 랭킹 규칙

- 메인 점수: 가장 높은 해금 균열 단계, 동률이면 최단 클리어 시간
- 제출 시점: 던전 공략 성공 직후
- 시즌: 2주 단위
- 노출: 상위 100명과 본인 주변 5명
- 자동 반복 중 같은 기록은 제출하지 않는다.

## 클라이언트 경계

1. `IRankingGateway`가 점수 제출과 순위 조회를 추상화한다.
2. 출시 전에는 로컬 구현으로 UI와 점수 산정만 검증한다.
3. PlayFab SDK를 설치한 뒤 `PlayFabRankingGateway`만 추가한다.
4. 비밀 키는 절대 클라이언트에 넣지 않는다. 클라이언트에는 PlayFab Title ID만 둔다.

## 필요한 외부 작업

- PlayFab 프로젝트 생성 및 Title ID 발급
- Google Play Games / Apple Game Center 로그인 정책 결정
- CloudScript 점수 검증 규칙 배포
- 개인정보처리방침에 계정 식별자·랭킹 데이터 처리 고지

현재 게임은 오프라인 플레이를 유지한다. 네트워크가 없으면 랭킹 제출만 보류하고, 전투·저장·오프라인 보상은 정상 동작한다.
