# 재미 설계와 문제 해결

## 결론

`상태창!!`의 재미는 **자동으로 싸우는 모습을 보는 것 자체**가 아니라, 플레이어가 만든 빌드가 예상대로 적을 압도하거나 예상 밖의 약점을 드러내는 순간에 생긴다.

따라서 게임의 중심은 “방치”가 아니라 아래의 짧은 실험이다.

```text
적의 위협을 읽는다
→ 이번 공략의 빌드를 가설로 세운다
→ 조작 없이 결과를 빠르게 본다
→ 왜 이겼거나 졌는지 즉시 이해한다
→ 새 보상으로 더 다른 가설을 시험한다
```

## 플레이어가 느껴야 하는 재미

| 순간 | 플레이어 감정 | 필요한 장치 |
| --- | --- | --- |
| 빌드 선택 | “이번에는 이 조합이 통하겠다.” | 적 특성, 예상 결과, 선택지 2~3개 |
| 전투 시작 | “내 선택이 실행된다.” | 헌터/적 레인, 즉시 시작하는 공격, 명확한 HP |
| 치명타·스킬·처형 | “내 빌드가 폭발했다.” | 큰 타격 차이, 고유 VFX/SFX, 짧은 카메라/스케일 변화 |
| 위기 | “이대로면 진다. 다음에는 바꿔야 한다.” | 장벽·폭주·시간 부족의 선명한 신호 |
| 보상 | “다음 판에는 다른 방식으로 강해진다.” | 숫자 증가보다 플레이 방식이 달라지는 장비/스킬 |
| 기록 갱신 | “내 빌드가 효율적이었다.” | 공략 시간, 이전 기록 비교, 다음 목표 |

## 현재 문제의 근본 원인과 해결

### 1. 전투가 ‘결과표’처럼 보인다

현재는 체력바와 숫자가 바뀌지만, 일반 공격·스킬·적의 특성이 서로 다른 장면으로 읽히지 않는다. 플레이어는 빌드의 결과를 **느끼기보다 계산해서 해석**해야 한다.

**해결:** 한 전투에서 최소 다섯 사건을 시각·청각적으로 분리한다.

- 기본 공격: 짧은 전진 + 작은 궤적 + 짧은 타격음
- 치명타: 금색 숫자 + 큰 섬광 + 강한 타격음
- 액티브: 고유 색의 큰 투사체/범위 효과 + 쿨다운 신호
- 적 장벽/폭주: 보라색 방벽/오라 + 전용 경고음
- 처치: 적 소멸 + 보상 흡수 + 짧은 만족감 있는 음

처음에는 헌터 1종, 일반 적 1종, 보스 1종으로만 완성한다. 모든 적에게 미완성 연출을 넣는 것보다 **10초짜리 전투 하나를 맛있게 만드는 것**이 먼저다.

### 2. 빌드 선택의 결과가 모호하다

스탯·스킬·장비 메뉴가 많아도 “무엇을 왜 선택하는지”가 분명하지 않으면 플레이어는 추천 수치만 따라간다.

**해결:** 초반부터 서로 다른 세 가지 빌드가 확실히 다르게 보이게 한다.

| 빌드 | 선택 | 보는 재미 | 카운터 |
| --- | --- | --- | --- |
| 연쇄 베기 | 근력·치명·처형 | 큰 숫자와 빠른 처치 | 장벽 적에게 약함 |
| 균열 포격 | 마력·액티브 | 주기적 큰 광역 폭발 | 빠른 적에게 시간 손해 |
| 불굴 방호 | 의지·방어·체력 | 버티며 역전 | 제한시간에 약함 |

각 던전은 ‘체력이 높은 적’이 아니라 한 가지 질문을 던져야 한다.

- 장벽 균열: “한 방이 강한가, 여러 번 때리는가?”
- 속공 균열: “빨리 죽이는가, 버티는가?”
- 폭주 균열: “반피 이후를 넘길 수 있는가?”

### 3. 보상이 숫자만 늘리고 다음 선택을 만들지 못한다

골드만 늘면 최적 구매 순서가 굳고, 반복은 노동이 된다.

**해결:** 보상은 최소 3개 중 하나의 새 선택을 열어야 한다.

- 새 스킬: 전투 장면이 달라진다.
- 새 장비: 특정 빌드가 가능해진다.
- 세트 조각: 다음 조각을 찾는 목표가 생긴다.
- 기록 보상: 더 빠른 공략을 시도할 이유가 생긴다.

장비 중복/미획득 상황에는 강화 재화 또는 교환 재화를 줘서 ‘빈 보상’을 없앤다.

### 4. 홈 화면이 메뉴와 전투를 모두 떠안는다

전투는 구경해야 하고, 상태창은 읽고 비교해야 한다. 한 화면에 둘을 모두 길게 넣으면 둘 다 약해진다.

**해결:** 홈을 `전투 감상 화면`, 상태창을 `빌드 작업 화면`으로 분리한다.

```text
홈: 자원 → 전투 → 고정 조작(입장/중단/반복) → 하단 탭
                         ↓
상태창 패널: 한 탭에 한 의사결정, 비교와 구매
```

전투 중단과 자동 반복은 스크롤 영역 밖의 고정 버튼이어야 한다.

### 5. 현재 아트는 원화이고 게임 에셋이 아니다

배경 포함 세로 원화는 상태창 일러스트에는 쓸 수 있어도, 전투 레인에서는 서로 겹치고 전장을 가린다.

**해결:** 같은 캐릭터를 다음 세 종류로 분리한다.

1. 상태창 초상화 — 고품질 정지 원화
2. 전투 스프라이트 — 투명 배경, 작은 실루엣, 애니메이션 중심
3. 스토어 키 아트 — 광고/스토어 전용 고품질 이미지

## 출시까지의 우선순위

### 단계 A — ‘재미가 있는 1분’ 만들기

- 헌터 1종 + 장벽 적 1종 + 보스 1종의 투명 전투 스프라이트
- 균열 옥상 배경 1종
- 일반/치명타/스킬/장벽/처치 VFX
- BGM 1곡 + SFX 10종
- 홈 전투 화면 재배치

**완료 판정:** 처음 보는 사람이 1분 안에 “치명타 빌드가 장벽에 약하네”를 화면만 보고 말할 수 있다.

### 단계 B — ‘다음 판을 하고 싶다’ 만들기

- 세 빌드의 고유 스킬 장면
- 적 특성 3종의 명확한 카운터
- 장비 세트 3종과 조각 획득 목표
- 중복 보상 교환 재화
- 기록 갱신 화면

**완료 판정:** 플레이어가 같은 던전을 최소 세 번, 서로 다른 빌드로 시도한다.

### 단계 C — ‘매일 들어온다’ 만들기

- 오프라인 보상 수령 연출
- 일일 의뢰와 주간 목표
- 보스/배경/보상 변주
- 보상형 광고는 이 단계 이후에만 연결

### 단계 D — ‘출시해도 된다’ 만들기

- Android 실기기 QA와 저장 복구
- 아이콘·스플래시·스토어 페이지
- 개인정보처리방침·문의·분석
- 이후 서버 검증 랭킹

## 결정

지금 가장 먼저 만들 것은 새 던전이나 새 스탯이 아니다. **전투 1분의 시각·청각·보상 피드백을 완성하는 것**이다. 이것이 해결되면 콘텐츠를 추가할수록 재미가 쌓이고, 해결되지 않으면 콘텐츠를 늘릴수록 메뉴만 복잡해진다.
