# 성장과 경제 기획

## 성장 축

| 축 | 얻는 곳 | 선택의 의미 |
| --- | --- | --- |
| 레벨·스탯 | 전투 경험치, 골드 구매 | 기본 화력·속도·생존 성향 |
| 스킬 노드 | 골드 | 액티브·패시브 조합 |
| 장비 | 던전 보상, 골드 | 슬롯별 빌드 변경 |
| 장비 강화 | 골드 | 보유 장비의 안정적 성장 |
| 장비 세트 | 특정 장비 조합 | 명확한 빌드 완성 보상 |
| 던전 숙련도 | 던전 공략 | 장기 누적 보정 |
| 회귀·계승 | 조건 달성 후 회귀 | 영구 성장과 재시작 동기 |
| 일일 균열 의뢰 | 일일 행동 | 짧은 접속 목표 |

## 경제 원칙

- 골드는 스탯 구매·스킬·장비·강화의 공통 재화다.
- 초반에는 한 번의 공략으로 다음 선택 하나를 할 수 있어야 한다.
- 장비가 막혔을 때는 강화·스킬·스탯 중 적어도 하나의 유효 선택지가 남아야 한다.
- 회귀는 손해가 아니라 다음 빌드의 출발 가속으로 느껴져야 한다.

## 출시 전 밸런스 검증

- 신규 유저 30분: 첫 회귀 조건이 너무 멀지 않은지
- 1일차: 자동 반복이 무의미하게 막히지 않는지
- 3일차: 장비 세트와 상위 스킬에 접근 가능한지
- 7일차: 모든 재화가 한 가지 행동으로만 수렴하지 않는지

## 결정 기록

- 일일 의뢰는 로컬 UTC 기준이다. 서버 도입 전에는 기기 시간 조작을 완전히 막을 수 없다.
- 공개 랭킹 보상은 서버 검증 전까지 연결하지 않는다.
