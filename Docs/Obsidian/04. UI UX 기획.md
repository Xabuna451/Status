# UI UX 기획

## 홈 전투 화면의 우선순위

1. 상단: 레벨, 골드, 스탯 포인트, 핵심 재화
2. 중앙: 전투 배경, 헌터/적, HP, 층/타이머, 사건 피드백
3. 중앙 하단: `균열 설정` 또는 `전투 중단`, `자동 반복` — 항상 고정
4. 하단 탭: 성장 / 스킬 / 장비 / 균열 / 업적 / 환생
5. 상태창 패널: 탭을 누를 때만 열리는 별도 스크롤 영역

## 필수 UX 규칙

- 전투 중에도 `전투 중단`은 한 번의 탭으로 접근 가능해야 한다.
- 자동 반복이 켜져 있으면 ON 상태와 중단 방법을 명확히 보여 준다.
- 하나의 카드에는 하나의 핵심 행동만 둔다.
- 텍스트만으로 희귀도·위험·활성 상태를 구분하지 않는다. 색+아이콘+문구를 함께 쓴다.
- 본문 텍스트는 최소 24px 기준, 주요 조작은 최소 56px 높이로 잡는다.

## 개선 대상

- 긴 설명이 나열되는 카드형 목록
- 전투 영역과 캐릭터 원화가 겹치는 구성
- 실제 기능보다 프로토타입 느낌이 강한 단색 사각 버튼
- 스크롤해야만 보이는 핵심 전투 조작
