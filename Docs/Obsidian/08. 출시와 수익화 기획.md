# 출시와 수익화 기획

## 출시 순서

1. Android 내부 테스트: 전투·UI·저장·오프라인 보상 검증
2. 소규모 비공개 테스트: 난이도 곡선·잔존·광고 피로도 확인
3. Google Play 공개 출시
4. 온라인 랭킹과 시즌 운영

## 권장 초기 수익화

- 보상형 광고: 오프라인 보상 2배, 던전 보상 2배
- 일일 제한과 재생 대기 시간을 둔다.
- 전면 광고·배너는 초기 버전에서 사용하지 않는다.
- 인앱 구매는 광고 제거와 순수 꾸미기부터 시작한다.

## 온라인 랭킹 원칙

- 클라이언트 점수만으로 랭킹을 만들지 않는다.
- 로그인, 서버 시간, 공략 제출 검증, 비정상 기록 차단이 필요하다.
- 초기에는 개인 최고 기록 화면만 제공하고, 공개 랭킹은 백엔드 검증 이후에 연다.

## 출시 차단 체크

- Android 적응형 아이콘·스플래시·서명 키·AAB
- 개인정보처리방침·문의 이메일
- 광고 동의와 미성년자/지역 정책 검토
- 실제 기기 해상도·저장 복구·오프라인 보상 테스트
- 스토어 스크린샷과 설명문
