# 핵심 플레이 루프

```text
오프라인/일일 보상 수령
        ↓
상태창에서 스탯·스킬·장비·세트 선택
        ↓
균열 선택 → 자동전투 시작
        ↓
클리어 / 시간 초과 / 패배
        ↓
보상·실패 원인·추천 투자 확인
        ↓
더 높은 균열 또는 더 빠른 기록에 재도전
```

## 첫 세션 10분 흐름

1. 기본 상태창에서 스탯 포인트 3~5개를 배분한다.
2. 훈련 균열을 자동전투로 공략한다.
3. 골드·경험치·첫 장비를 받는다.
4. 장비 장착 또는 스킬 해금으로 빌드를 바꾼다.
5. 자동 반복을 켜거나 더 높은 균열로 간다.

## 실패 설계

| 결과 | 화면에 보여 줄 원인 | 다음 행동 |
| --- | --- | --- |
| 시간 초과 | DPS 부족 또는 이동 지연 | 근력·민첩·치명·액티브 투자 |
| 패배 | 체력·방어 부족 | 의지·방어 장비·생존 세트 |
| 클리어 | 기록 갱신 가능 여부 | 상위 균열, 위험 프로토콜, 자동 반복 |

## 반복의 보상

- 즉시: 골드, 경험치, 장비, 장비 강화 재화
- 중기: 스킬 조합, 장비 세트, 던전 숙련도
- 장기: 회귀 파편, 계승 특성, 기록 경쟁
