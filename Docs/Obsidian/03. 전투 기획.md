# 전투 기획

## 전투 규칙

- 캐릭터는 자동으로 적을 찾고 공격한다.
- 각 층에는 처치 목표와 제한 시간이 있다.
- 제한 시간 안에 처치하지 못하면 강제 탈출한다.
- 전투 중 빌드는 잠기며, `전투 중단`으로만 즉시 해제할 수 있다.
- 자동 반복은 클리어한 경우에만 다음 공략으로 이어지고, 실패·중단 시 정지한다.

## 화면에서 반드시 읽혀야 할 것

1. 현재 층 / 남은 시간 / 처치 목표
2. 헌터와 적의 HP
3. 현재 공격 사건: 일반·치명타·스킬·피격·처형
4. 보스 또는 적의 특성: 속공·장벽·폭주
5. 전투 중단과 자동 반복 상태

## 전투 연출 기준

| 사건 | 최소 연출 | 출시 목표 |
| --- | --- | --- |
| 일반 공격 | 전진 20~40px, 적 타격 섬광, 숫자 | 무기 궤적, 짧은 타격 SFX |
| 치명타 | 금색 숫자, 확대, 강한 섬광 | 화면 미세 흔들림, 전용 VFX/SFX |
| 자동 액티브 | 큰 투사체 또는 범위 효과 | 스킬별 고유 색·사운드 |
| 적 공격 | 적 전진, 헌터 피격색 | 피격 경직, 위험 HP 효과 |
| 처형 | 적 HP 제거와 큰 텍스트 | 짧은 슬로모션/균열 파열 |
| 적 처치 | 적 퇴장, 보상 피드백 | 소멸 VFX·전리품 흡수 |

## 시각 배치 원칙

- 헌터는 왼쪽 40%, 적은 오른쪽 40%의 고정 전투 레인에 둔다.
- 배경은 전체 전장을 담당하고, 캐릭터는 반드시 투명 배경 스프라이트를 쓴다.
- 캐릭터 원화의 배경색·프레임은 전투에 사용하지 않는다.
- 전투 UI는 하단 조작부를 침범하지 않는다.
