# 상태창!! 개발 볼트

이 폴더는 Obsidian에서 그대로 열 수 있는 게임 기획·제작 기준 볼트다. 지금의 목표는 **세로형 모바일 자동전투 성장 RPG의 내부 테스트 빌드**이며, 출시 전 결정과 제작물을 여기에서 관리한다.

## 먼저 읽을 문서

1. [[01. 제품 정의]] — 누구에게 무엇을 파는 게임인지
2. [[02. 핵심 플레이 루프]] — 플레이어가 반복하는 행동
3. [[03. 전투 기획]] — 조작 없는 전투가 재미있어지는 조건
4. [[04. UI UX 기획]] — 모바일 한 화면의 우선순위
5. [[05. 성장과 경제 기획]] — 스탯·스킬·장비·회귀·일일 의뢰
6. [[06. 아트 디렉션]] — 시각 기준과 금지 요소
7. [[07. 사운드 기획]] — 전투 피드백 기준
8. [[08. 출시와 수익화 기획]] — 내부 테스트부터 수익화까지
9. [[09. 개발 로드맵]] — 작업 순서와 완료 기준
10. [[10. 에셋 마스터 리스트]] — 필요한 에셋 전체 목록

## 현재 제품 원칙

- 스토리는 만들지 않는다. 플레이어의 목적은 빌드와 기록 갱신이다.
- 전투 중 직접 조작은 없다. 입력은 전투 전 빌드, 반복, 수령, 메뉴 선택에 한정한다.
- 모바일 세로 화면이 기준이다.
- 오프라인 보상은 존재한다. 다만 랭킹은 서버 검증 전까지 공개 경쟁으로 취급하지 않는다.
- UI와 전투 결과는 즉시 읽혀야 한다. 정보량보다 다음 행동의 명확함을 우선한다.

## 사용법

- 새 작업은 [[09. 개발 로드맵]]의 해당 단계에 체크한다.
- 새 에셋은 [[10. 에셋 마스터 리스트]]에 상태와 권리 출처를 기록한다.
- 기능·밸런스 결정을 바꾸면 관련 문서의 `결정 기록`에 날짜와 이유를 남긴다.
