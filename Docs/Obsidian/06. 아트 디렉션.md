# 아트 디렉션

## 시각 키워드

현대 한국 도시 판타지 / 심야 균열 / 딥 네이비 / 시안 네온 / 제한된 바이올렛 / 날카로운 상태창 프레임.

## 원칙

- 인물 원화보다 게임 안에서 읽히는 전투 스프라이트를 우선한다.
- 캐릭터·적·VFX의 실루엣은 작은 모바일 화면에서도 구분돼야 한다.
- 배경과 캐릭터를 하나의 이미지에 합치지 않는다.
- 보스만 과도하게 복잡하고 일반 몬스터가 밋밋해지는 구성을 피한다.
- UI는 웹툰 패널이 아니라 게임 HUD로 설계한다.

## 금지 요소

- AI 특유의 번진 손, 중복 장신구, 읽히지 않는 가짜 문자
- 불투명 사각 배경이 포함된 캐릭터 원화의 전투 사용
- 너무 많은 보라색 광원으로 HP·피격·희귀도를 구분할 수 없는 화면
- 기존 유명 웹툰/게임을 연상시키는 고유 복장·무기·로고
