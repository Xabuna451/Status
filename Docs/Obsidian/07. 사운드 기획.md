# 사운드 기획

현재 실제 BGM/SFX 파일은 없다. 사운드는 전투의 타격감을 만드는 출시 차단 항목이다.

## BGM

| ID | 용도 | 길이/루프 | 분위기 |
| --- | --- | --- | --- |
| BGM_LOBBY_01 | 홈·상태창 | 90초 이상 루프 | 낮은 신스, 긴장 전의 균열 도시 |
| BGM_BATTLE_01 | 일반 균열 | 60초 이상 루프 | 빠른 퍼커션, 시안 신스 |
| BGM_BOSS_01 | 보스/상위 균열 | 60초 이상 루프 | 무거운 저음, 바이올렛 긴장 |

## SFX 최소 14종

- UI 탭, 버튼 확인, 창 열기/닫기
- 스탯 투자, 스킬 해금, 장비 장착, 강화 성공
- 일반 타격, 치명타, 스킬 발동, 적 피격, 적 처치
- 보상 수령, 던전 클리어, 시간 초과, 패배

## 믹싱 원칙

- 일반 타격은 짧고 낮게, 치명타·스킬·처치는 구분되게 크게 만든다.
- 자동전투가 장시간 반복되므로 고음·긴 잔향을 남발하지 않는다.
- BGM/SFX/진동의 개별 토글과 전체 음량 설정을 출시 전에 제공한다.
